# 力学シミュレーション集

ブラウザで動作するインタラクティブな力学シミュレーションのコレクションです。各シミュレーションは単一のHTMLファイルで完結しており、外部依存なしで動作します。

## 使い方

任意のHTMLファイルをダウンロードしてブラウザで開くか、GitHub Pagesで直接実行できます。
